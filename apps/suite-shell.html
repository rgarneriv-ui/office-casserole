Office Casserole — working vertical slices

Pick an app above. Things worth trying:

  • Write — type with Ctrl/Cmd-B, watch the Reveal Codes panel; Ctrl/Cmd-K for the command palette; ⊞ inserts a table (click cells, Tab walks the grid); ⧗ Revisions shows your attributed edit history, compare & restore included.
  • Sheets — click a cell, type =SUM(D2:D4) or =IF(D6>300, "YES", "no"); edits ripple through dependents; try a circular reference and watch #CYCLE! appear and recover.
  • Slides — drag elements, double-click text to edit in place, ▶ presents (arrow keys navigate, Esc exits).

Everything is a real engine underneath — typed document models, an invertible operation log, deterministic recalculation — not a mock-up.
